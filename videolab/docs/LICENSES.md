# Üçüncü taraf lisanslar (doğrulayın: sürümler değişebilir)
- PySide6 (Qt for Python): LGPLv3 – dinamik bağlama ile uyumlu; EXE dağıtımında Qt lisans metnini ekleyin.
- FFmpeg: LGPL/GPL (derlemeye bağlı). libx264/libx265 içeren "GPL" derlemeler dağıtılan paketi GPL'e bağlayabilir.
  FFmpeg'i ayrı süreç olarak çağırmak bu riski azaltır; EXE'ye FFmpeg gömecekseniz derleme lisansını inceleyin.
  H.264/H.265 için bazı ülkelerde patent lisansı gerekebilir.
- faster-whisper: MIT; Whisper model ağırlıkları: MIT (OpenAI). Silero VAD: MIT.
- NumPy/SciPy: BSD; OpenCV: Apache-2.0.
